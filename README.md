# F1 SIMULATOR
Proyecto desarrollado en la materia de "Programación orientada a objetos" por:

- Arias Hernández Javier
- Mireles Rubio Carina
- Otros.

El siguiente proyecto desarrollado con Java permite crear la simulación de un gran premio de Formula 1. El usuario puede generar desde cero pilotos, circuitos, etc. Así mismo también puede acceder a datos predeterminados dentro del programa.
